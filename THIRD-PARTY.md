# Исходники и лицензии

- Основа прошивки — MeshCore. Исходный снимок закреплён в скрипте сборки, изменения находятся в каталоге `patches/`. [Исходники MeshCore](https://github.com/meshcore-dev/MeshCore/tree/81dbae592ffad40b4212bc0b37e82b38da08f4bc) · [MIT](LICENSE)
- Heltec использует Arduino Core for ESP32 2.0.17 и библиотеки ESPAsyncWebServer 3.10.3 и AsyncTCP 3.5.0. Последние две распространяются по LGPL 3.0. Скрипт сборки использует опубликованный код приложения и позволяет заменить библиотеки и пересобрать образ. [Arduino ESP32](https://github.com/espressif/arduino-esp32/tree/2.0.17) · [Лицензия Arduino ESP32](licenses/arduino-esp32.txt) · [ESPAsyncWebServer 3.10.3](https://registry.platformio.org/libraries/esp32async/ESPAsyncWebServer/versions/3.10.3) · [AsyncTCP 3.5.0](https://registry.platformio.org/libraries/esp32async/AsyncTCP/versions/3.5.0) · [LGPL 3.0](licenses/LGPL-3.0.txt) · [GPL 3.0](licenses/GPL-3.0.txt)
- FakeTec использует Arduino Core для nRF52 из форка MeshCore. UF2 содержит образ приложения. [Исходники Arduino nRF52](https://github.com/meshcore-dev/Adafruit_nRF52_Arduino/tree/d541301665b40959682252911e57b11df3ee651a) · [Лицензия](licenses/Adafruit-nRF52.txt)
- [Конфигурация выпуска](platformio.releases.ini) указывает версии остальных библиотек и исходные репозитории для зависимостей Git. PlatformIO скачивает их вместе с исходными уведомлениями и лицензиями. [RadioLib](https://github.com/jgromes/RadioLib/tree/6d8934836678d8894e3d556550475b37dce3e2b6)
